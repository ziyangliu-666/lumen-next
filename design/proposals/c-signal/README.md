# Direction C: Signal

Swiss information design, read like transit signage. State is a solid colour
field, never a pill. Home is a departures board: each row starts with a
two-column field that carries the state word. The session call tree is a line
diagram: one black trunk, station dots, branch spurs.

## Colour

- Ground `#E9EAEC`, sheet `#FFFFFF`, ink `#000000`, body `#1F2328`,
  secondary `#62666D`, rule `#CDD0D4`. Header band `#000000`, white type.
- decide `#F2B705`, black text (11.6:1).
- gap `#D7263D`, white text (4.96:1).
- keep `#0A7B55`, white text (5.28:1).
- open `#1F4FD8`, white text (6.6:1).
- dropped `#9AA0A6`, black text (7.9:1). White text fails AA here (2.6:1).
- Running is a black field. Only states that need a person get colour.

## Type

Host Grotesk 400/500/700. IBM Plex Mono for code, paths, terminal.
Scale 13, 15, 18, 24, 36, 56, 96. Headlines 700, tracking -0.03em.
Tabular numerals for money, time and counts.

## Grid

12 columns, 20 px gutter, 40 px margin (24 below 1024 px, 16 below 640 px).
8 px baseline. Radius 0. Press G to show the grid.
